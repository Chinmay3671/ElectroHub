Home

Welcome to ElectroHub, a simple electronics shopping portal created as a college mini-project.

This web application showcases a catalog of fundamental electronic components such as microcontrollers, IoT boards, sensors, and prototyping accessories. Students and hobbyists can explore components, review technical descriptions, and simulate managing their electronics shopping cart.

Project Note: This frontend provides a clean, visual representation of the store interface. The backend RESTful API is powered by Java Spring Boot and MySQL.

Resources

Helpful external websites and online simulation tools for electronics students:

  • OnlineGDB C Compiler: https://www.onlinegdb.com/online_c_compiler - Online compiler and debugger for C and embedded systems programming.
  • Wokwi Simulator: https://wokwi.com/ - Browser-based electronics simulator for Arduino, ESP32, and Raspberry Pi Pico.
  • Tinkercad Circuits: https://www.tinkercad.com/circuits - Autodesk interactive web platform for designing and simulating breadboard circuits.
  • Wikipedia Electronic Components: https://en.wikipedia.org/wiki/Electronic_component - Reference encyclopedia article on basic discrete and active electronic components.
