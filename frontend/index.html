Welcome to ElectroHub, an electronics shopping portal created as a college mini-project.

This web application showcases a catalog of fundamental electronic components such as microcontrollers, IoT boards, sensors, and prototyping accessories. Students and hobbyists can explore components, review technical descriptions, and simulate managing their electronics shopping cart.

System Architecture:

  • Frontend: HTML5, CSS3, and JavaScript REST Client (Running on Port 3000)
  • Backend: Java 17+, Spring Boot 3.2.5 RESTful Web Services (Running on Port 8081)
  • Database: MySQL 8.0+ Persistence with Spring Data JPA & Hibernate
